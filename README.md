# Insurance Portal

## 📌 Overview
The Insurance Portal is a web-based application designed to simulate an online insurance system.  
It provides structured pages for insurance applications, policy details, and user interaction.  
This project demonstrates my skills in **React, TypeScript, and modern frontend development**, as well as project structuring with **Vite** and version control using **Git/GitHub**.

## 🛠️ Tech Stack
- **Frontend:** React, TypeScript, Vite  
- **Backend (basic setup):** Node.js  
- **Version Control:** Git & GitHub  
- **Other Tools:** npm, VS Code  

## ✨ Features
- User-friendly interface with structured navigation  
- Pages for insurance application and policy details  
- Responsive design for desktop and mobile  
- Clean project setup using Vite + TypeScript  
- Version control with Git/GitHub  

## 🚀 How to Run
1. Clone the repository:  
git clone https://github.com/yourusername/insurance-portal.git

2. Navigate into the project folder:
cd insurance-portal

3. Install dependencies:
npm install

4.Start the development server:
npm run dev
